# 老师排课小程序

这是一个独立运行的老师排课小程序，适用于教师快速管理课程、查看周安排、检查时间冲突，并持久化保存排课信息。

## 功能特性

- 课程录入：添加老师、课程、学生、日期、教室、时间
- 周视图：按周一到周日展示课程安排
- 冲突检测：自动提醒时间重叠课程
- 课程列表：查看已安排课程并支持删除
- 本地存储：使用浏览器 localStorage 保存数据，刷新后不丢失
- 无依赖运行：直接打开 `index.html` 即可使用

## 运行方式

### 方式 1：直接打开

在浏览器中直接打开：

`index.html`

### 方式 2：本地静态服务器

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

`http://localhost:8000`
